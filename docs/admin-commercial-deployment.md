# GYUTRON Operations — 独立实例商业交付手册

更新：2026-11-03。适用源码版本 `2026.11.03.7`、迁移0001–0010、备份格式4。本文记录实现与交付要求，不表示新版已通过生产验收。实际commit、制品hash、部署及检查结果以随包manifest、发布记录和 `HANDOFF.md` 为准。

## 1. 产品与交付边界

每客户使用独立Worker、D1、私有R2和限流KV。客户名称或instance_id不是共享数据库的租户隔离。本产品没有共享库多租户、自助开户或订阅计费；独立部署、配置、维护与支持可以作为商业交付，但不等于已完成法律合同、SLA或第二客户生产验收。

| 模块 | 当前实现与边界 |
|---|---|
| CRM与原有运营 | 网站提交收件箱/内部备注、客户/联系人/商机/任务/活动、转换、关联详情/时间线、保存视图、筛选导出、逐项批量结果、归档恢复和并发冲突；旧订单请求/事件运营页继续受保护 |
| 工业报价 | 单币种精确minor整数计算、手填折扣/税额/运费、草稿、签发冻结快照、修订、内部客户反馈、四语打印；不自动发送、收款或开税务发票 |
| 数据与经营分析 | 本实例网站数据、真实CSV预览/导入和本地collector；按来源归一订单/明细/客户/付款，去重及续传；按来源/币种/日期查看摘要与明细 |
| 规则/自动化/报告 | 13种固定规则与政策、真实发现和任务、运行历史/失败重试、间隔或业务时区日历调度、持久化报告；不执行任意用户代码 |
| Agent/Memory/资料 | 真实私有会话、消息、运行、记忆及文本资料；可选CRM/近30天经营摘要、规则、记忆与资料片段，保留来源；默认本地确定性回答，外部模型须另行配置并逐次同意 |
| 通知/管理 | 真实任务/新询盘/自动化失败/本人Agent失败通知和独立已读回执；用户、审计、安全、备份、健康、实例与许可证状态；不向外发送通知 |

旧Agent的Agent Chat、Ecommerce Dashboard、Data Sources、Reports、Automations、Tasks、Memory、Business Rules、Audit Logs、Security、Backup、License、Health、Users对应以上实际功能，不以菜单存在冒充集成完成。工作台固定文案仅支持English与中文，首次访问默认English；旧德语/日语界面链接回落English。用户正文与历史报告/打印不自动翻译或删除。

独立starter只提供受保护 `/admin`、必要品牌静态资源及最小 `/health`，根路径跳转 `/admin`。不提供官网公共表单、公共Data API、Shop主机映射/下单或支付路由。收件箱表存在不表示客户官网已接通；主站可读取自身已有提交，独立客户须另行接入验收。

## 2. 源码、品牌与许可

业务层为JavaScript、Web APIs与SQL，运行于Cloudflare Worker/D1/R2/KV。没有使用Salesforce、HubSpot、Odoo、ERPNext或Twenty源码作为底座，不宣称官方合作或集成。

独立包锁定Node24、Wrangler4.93.1（包声明 `MIT OR Apache-2.0`）；workerd遵循Apache-2.0，SQLite核心为public domain。官网Astro为MIT，独立工作台无需官网构建链。具体版本、适用LICENSE/NOTICE见锁文件及 `admin-technology-notices.md`。workerd开源不表示整套Cloudflare托管服务可按本包直接自托管。

自有业务源码的分发/修改/支持权由实际商业协议约定；`private:true`不是开源许可。包核验通过不替代合同、隐私条款及商标授权。GYUTRON名称/logo/外链和打印发行方资料须逐客户检查，修改显示名称不等于完整白标。

正式包应固定commit，包含锁文件、迁移、配置模板、检查脚本、运维文档和逐文件SHA。排除生产资源ID、环境文件、OAuth缓存、客户资料、数据库导出、R2快照、恢复SQL、cookie、模型原文key及签发私钥。不要直接压缩整个工作目录。

## 3. 部署、身份与配置

以starter README真实命令为入口：校验包 → `npm ci` → `npm run check`/`npm test` → 独立资源/配置 → 本地迁移/验收 → 受控设置secret → 保留恢复点 → 增量远程迁移 → 部署 → 实际域名验收。配置脚本只创建新配置，不创建云资源、不覆盖已有配置、不设置secret。确认 `DB`、`R2`、`RATE_LIMIT`、`ASSETS` 指向目标客户。

| 配置 | 要求 |
|---|---|
| `ADMIN_WORKSPACE_NAME`、`DATA_SOURCE_ID`、`DATA_SOURCE_NAME` | 本实例名称与来源标识，不是共享租户隔离 |
| `ADMIN_TIMEZONE` | IANA业务时区；存储UTC，业务日期与日历调度用该时区 |
| `ADMIN_LOGIN_MODE` | 默认仅owner密码；客户明确选择后设 `team` 显示可选员工邮箱入口 |
| `ADMIN_PASSWORD` | 所有者选择的Worker secret，不写仓库；GYUTRON按用户决定保留共享密码方式，不擅自轮换 |
| `ADMIN_SECRET`、`IP_HASH_SALT` | 各实例独立随机secret；owner secret轮换使已有owner会话失效 |
| `WORKSPACE_ENCRYPTION_KEY` | 至少32字符高熵独立master secret，AES-GCM加密模型凭据；快照不包含，另行保管 |
| `MODEL_API_ALLOWED_HOSTS` | 可选自定义模型HTTPS主机白名单，仅开放确有必要的受控主机 |
| `LICENSE_VERIFY_PUBLIC_KEY` | Ed25519公钥SPKI base64url，用于验签，不是签发私钥 |
| `INTELLIGENCE_OWNED_DEPLOYMENT` | 仅真实自有部署设 `true`，不能伪造付费客户激活 |

秘密通过交互式 `wrangler secret put` 或受控系统注入，不出现在命令参数/截图/日志，不跨客户复用。独立包没有公共Data API，无需为该入口配置 `DATA_API_KEY`。

共享owner的审计身份、私有会话与通知回执属于同一部署principal，不代表每位自然人员独立身份或隐私。需要员工级归属时明确启用team并创建具名用户。staff使用随机salt+scrypt，opaque会话仅存hash，每请求核对active/role，退出/停用/相关身份变更撤销。无邮件自助邀请/找回、SSO或MFA；权限须负向API验收，不以隐藏按钮代替。

## 4. 来源、金额与自动化

CSV支持 `orders`、`order_items`、`customers`、`payments`，预览映射/错误后提交；单份最多1MiB、500行，请求上限2MiB。规范记录按来源与外部ID幂等写入，模糊重复行须补稳定ID，不按行序编造明细身份。不是所有CRM对象的通用导入器。

`scripts/local-source-sync.mjs`读取指定目录直属CSV，或同步 `.txt`/`.md` 资料；密码从进程环境读取。它实际上传选定内容、保存hash/续传状态；不是已安装Windows服务，不递归扫描，不自动读取旧Agent库/环境秘密，不解析PDF/Office正文。每个目标/来源/实体用独立目录，本地删除不会删除远程记录。完整命令见starter README。

订单指标是“已付订单金额（退款前）”：paid/fulfilled/partially_refunded/refunded订单原总额各计一次。导入付款台账分别报告paid/refunded及差额，不与订单金额重复相加；差额不是会计净收入，也不证明台账完整。币种分别聚合，精确minor字符串避免不安全浮点，无自动汇率换算。商机和报价不等于收入。

13种规则/政策：询盘跟进、支持审核、下载审核、数据卫生、重复询盘、产品机会、弃购信号、已付未履约、高浏览无询盘、RFQ激增、优先国家、优先类别、内部测试排除。后3项涉及优先级/统一排除，政策版本进入运行/报告。匿名信号不冒充已识别弃购客户。发现去重、复现重开、失败重试均留真实记录；暂停不表示取消已排队快照。

每分钟cron推进有限工作；业务IANA时区日历或间隔调度不是精确到秒的SLA。明细有维护保留策略，报告/发现引用记录受保护，不宣传全部运行明细永久保存。工作区内故障通知不等于外部告警接收已接通。

## 5. Agent、模型与许可证

资料真实保存文本/Markdown全文、文件名、来源、版本与存储文本SHA；单份最多200KiB UTF-8（204800字节），每次会话最多选8份，不是整个库只能存8份。每份最多12000字符相关片段，记录截取位置/截断，上下文另有总预算。检索为文字匹配/窗口，不宣称向量搜索或全格式解析。Memory支持分类、搜索、来源、有效期及归档。

默认Agent不调用外部模型；选择真实CRM/近30天经营精简摘要、规则、记忆和资料，回答保留来源。工具仅受控只读查询与跟进/报告草稿，不自动发送邮件、拨号或变更外部平台。上下文勾选不等于外发同意。

模型仅接受已知provider或明确白名单HTTPS主机，拒绝本地/IP/带凭据URL和重定向。换provider/主机须新key或清除停用，不能沿用旧供应商key。AES-GCM保存凭据，API不回显key；逐次外部请求需摘要发送同意及当前配置版本，发精简事实/选定摘录/有界历史，不发送原始大表。模型测试会真实联系供应商，须明确执行；协议替身和本地问答不构成真实外部LLM验收。

许可是真实Ed25519验签、精确instance_id、期限与激活历史。离线 `scripts/issue-instance-license.mjs` 只签发文件，不创建/上传/自动激活实例；公钥进客户Worker，未加密PKCS8私钥留仓库外受限签发环境。Windows `mode:0600`不等于NTFS ACL，仍须运营者设置访问控制。`--help`展示命令。未配置/未激活如实显示，自有部署与付费激活分开。既有功能不会自动被许可证阻断，不是DRM、订阅收费或完整权益强制执行。

## 6. 备份、恢复与发布移交

格式4覆盖43张持久业务表，含 `d1_migrations` 时44张数据表；会话/登录尝试只恢复空结构。导入/规则/报告、Agent/资料/模型密文、联系人/视图/通知回执均在清单内。上限25000行、8MiB完整JSON（元数据预留256KiB），超限明确失败，不截断。较大实例须另验原生导出/Time Travel或分块方案。

私有R2回读验证整文件SHA后写commit marker；保留30个verified daily日期、12个weekly日期。无marker旧对象/孤儿不占名额，不自动清理。owner可手动备份、看verified列表和受保护下载；JSON不是整体加密文件，含客户/聊天与用户hash，按敏感数据保管。

必须独立保管并恢复原 `WORKSPACE_ENCRYPTION_KEY`；缺失时模型密文不可解，只能找回同一master或重新录入key。签发私钥不随客户快照交付。详细命令与长文本分段SQL机制见 `admin-backup-recovery.md`。

本版已真实隔离D1恢复44张数据表，计数一致；200KiB及另7份资料全文一致，integrity ok/外键0/staging表0。此结果不证明生产恢复、新客户部署、cron实际执行或RPO/RTO。0007–0010已在生产应用，应用发布/生产验收仍按发布报告确认，不能从迁移成功推断。

代码回退须已知兼容0010/格式4；旧2026.11.03.2不覆盖新表，不是本轮完整回退下限。Worker回退不回滚数据。禁止把旧快照直接覆盖仍接收业务的生产库，先恢复新目标再维护切换。

逐客户移交至少核实：资源归属/包hash；登录/角色/撤销；真实来源/导入幂等；CRM关系/冲突/归档；报价计算/冻结/打印；启用规则/日历/失败重试；Agent来源与外发同意；通知身份范围；私有R2/容量/secret恢复；移动端与键盘；告警接收者/升级责任。未接通集成、第二客户、远程恢复、告警接收演练、会计/支付/库存ERP及SLA须如实列为未具备或未验证。
