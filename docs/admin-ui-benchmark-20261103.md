# GYUTRON 工作台视觉与交互对标

研究日期：2026-11-03；本轮起点：`7d886a4`。范围为CRM工作台与其经营/Agent/管理扩展，目标用户是实际处理询盘、客户、跟进与报价的员工。本文不是品牌排行榜，也不声称完整复制任何CRM/ERP。

**当前状态：官方基准研究已完成；GYUTRON新版实现待独立视觉验收。** 测试接口成功、页面无横向溢出，不自动等于视觉达到本标准。本轮产品语言目标为English/中文；德语/日语旧链接回落英语，不据此删除历史业务内容。

## 1. 统一方向与来源边界

以Attio的对象列表与上下文预览为CRM主体，采用Linear的安静导航、固定层级和一致工具位置；经营数字与系统设置借鉴Stripe的清晰分组；客户详情借鉴HubSpot的属性、活动、关联分区。保留GYUTRON真实品牌与克制工业气质、石墨文字、近白背景与品牌紫色动作，不把四家不同皮肤拼到一个页面。用户本轮UI要求优先：后台控件采用约6px、卡片约8px的小圆角，官网既有直角系统不受此后台调整影响。

以下尺寸是本轮实现负责人确定的GYUTRON设计值，**不是对各品牌登录后产品的像素测量**：侧栏232px、顶部栏56px、正文/表格14px、导航13px、页面标题26–28px、主表行48px、8px间距基准与低对比分隔。详情/表单随内容增高，移动端触控目标单独放大，不能为了密度牺牲阅读。

字体采用自托管InterVariable，中文使用系统CJK回退；品牌采用官网原PNG字标1550:260及原mark344:311，不再使用重绘字标。图标采用同一套官方Lucide（含其继承的Feather图标许可通知），避免字体字符/emoji混充导航图标。这些是已选定源码方案，加载、清晰度、对齐与对比度仍待浏览器验收。[Inter官方与OFL](https://rsms.me/inter/)，[Lucide官方许可](https://lucide.dev/license)。

唯一直接测量：Stripe Apps官方DataTable演示中的姓名文字为系统sans-serif、14px、行高20px、字重400。该结果只属于官方组件演示，不冒称Stripe已登录Dashboard的通用字体。Attio、Linear、HubSpot产品截图只能支持可见层级/结构，无法从缩放截图证明其原始CSS字号、速度或键盘行为。

本次仅访问官方公开帮助页、组件演示和设计复盘，不注册账号、不修改第三方数据。官方营销插图与文档截图不构成实际产品完整审计。IAB实际不可用，改用独立Chrome研究标签；原生产/旧Agent标签未用于研究操作。

## 4. 新版独立视觉验收方法

1. 记录待验源码commit/Worker版本、本地隔离数据来源、实际CSS viewport与浏览器zoom，防止把767px写成768px。
2. EN/zh各检查桌面1440、移动390与320；补768边界。核心路线至少覆盖登录、Overview、客户列表/详情/编辑、任务、报价、来源、Agent、设置；无需每个页面同屏塞满功能。
3. 每个核心流程保存本轮真实截图并重新打开：初始/加载后、筛选/选中、详情/表单、错误/成功、窄屏导航。对照相同任务/区域的参考图，报告结构差异与我方品牌选择，不宣称异构产品像素一致。
4. 实际操作搜索/保存视图、详情开关、dirty取消、字段错误、键盘焦点和通知；检查表格滚动/对齐、logo自然比例与清晰度。只看截图不能证明动效、键盘或无障碍完整合规。
5. 以P0/P1未关闭数量决定是否可交付；只把已检查行改为通过并写证据。未覆盖路线保留待验，不以既有API测试补写视觉通过。

本文件及本轮专属QA artifacts由独立审查agent维护；runtime、品牌资产选择和发布由实现负责人处理。研究图仅作内部对标，不复制第三方商标/专有资产进产品。
